## 2. 测试素材（脚本合成）

语音由语音合成生成：首选 `edge-tts`（只发送下列合成文本，不含任何客户内容），不可用时退回 `espeak-ng`。每句单独合成，浏览器内按固定时间表拼接播放，句间停顿 1.6 秒，因此每句的开始、结束时刻（相对播放开始）精确已知。

| 素材 | 内容 | 用途 |
| --- | --- | --- |
| KO-5 | 韩语 5 句清晰短句（问候与感谢、销售增长、产品发布、客户满意度、欢迎提问） | IQA-301、IQA-303、IQA-304、IQA-305、IQA-307、IQA-312 |
| JA-5 | 日语 5 句清晰短句（同类主题，句中含假名） | IQA-302 |
| KO-LONG | 韩语 3 句：短句 + 一句约 8 秒的长句 + 短句 | IQA-306 |
| EN-4 | 英语 4 句清晰短句，每句附中文关键词表（用于“与原意一致”的宽松判定） | IQA-311 |
| ABORT-TEXT | 韩语长文本（约 6 句），保证流式译文持续数秒 | IQA-308、IQA-309 |

句子与请求的对应：每句给出若干只在该句出现的源语言关键词；浏览器发出的 `/api/translations` 请求中，主文本字段（`text`/`sourceText`/`source`/`input`/`content` 等，否则取最长的顶层字符串字段）含某句关键词即视为该句的请求。

## 3. 判定方法

- **中文判定（FR-301）**：一段文字判为“中文”当且仅当：不含谚文（U+1100–11FF、U+3130–318F、U+A960–A97F、U+AC00–D7AF、U+D7B0–D7FF）；不含日文假名（U+3040–309F、U+30A0–30FF、U+31F0–31FF、U+FF66–FF9F；其中 U+30FB 中点是标点、不计为假名）；不含汉字、拉丁字母以外的其它文字字母（西里尔、希腊、泰、阿拉伯、希伯来、天城文等）；至少含一个汉字。数字、标点、空白、符号与拉丁字母不影响判定。全汉字日文按 FR-302 判为中文（接受的局限）。
- **中文提示**：文字含“此句未能翻译成中文”。
- **字幕记录**：浏览器内用 MutationObserver 记录主页面字幕区与小窗文档的每一次变化（时间、各条目文字、类名、计算样式）。字幕条目的定位：优先选择属性或类名含 caption / subtitle / transcript 或带 `role=log` / `aria-live` 的容器，取其直接子元素；找不到时退回“开始后新出现的叶子文本块”（依赖假设 A-2）。
- **定稿字幕**：素材播放结束后，等待最后一次 `/api/translations` 请求结束满 4 秒（至少 8 秒、至多 30 秒），此时字幕区的条目（连同已滚出字幕区的较早条目）视为定稿字幕，再点击“停止”。
- **受控触发（G2 决定 I1 / TD-310）**：用浏览器初始化脚本包装 `window.fetch`，只对指定句子的 `/api/translations` 请求改写响应，其余请求原样走真实服务；生产代码不需要任何测试开关。改写方式与响应格式无关：把真实响应流中的每个汉字（含 `\uXXXX` 转义形式）替换为谚文“한”，使该结果按 FR-301 判为“非中文”。
- **定稿请求与重新翻译请求的区分**（依赖假设 A-3）：请求体中名称含 `retrans` 且值为真者为“重新翻译”请求（G2 决定 I2：服务端新增可选 `retranslate` 字段）；请求体有可识别的定稿/临时标记（键名含 final/stage/phase/kind/mode/type，或值为 final/interim/partial）时按标记区分；无标记时，该句音频结束 0.2 秒后发出的非重新翻译请求视为定稿阶段请求（句末之后迟到的临时请求被一并改写，按 FR-304 也不得显示，判定不受影响）。
- **日志级别**：日志行文本为 JSON 时取 `level` 字段（数字 ≥50 或字符串 error/fatal/critical 为 error/fatal 级）；非 JSON 行中出现 `level=error`、`[ERROR]`、`FATAL`、`Unhandled`、`uncaught`、以 `Error:` / `xxxError:` 开头的行同样计为 error/fatal 级。`client_aborted` 记录：行文本含 `client_aborted`，且级别为 info（数字 30 或字符串 info）。
- **日志时间窗**：每个中止操作的时间窗为“发送请求前 1.5 秒”到“随后的正常请求完成后 3 秒”；相邻时间窗至少间隔 5 秒，期间不运行其它测试流量。只有 `status.json` 的 `status` 为 `ok`、`logsReadAt` 晚于时间窗结束、时间窗不在 `gaps` 中时，才据日志作出判定；否则该检查记为环境或平台问题（不计为产品缺陷）。

## 6. 验收场景

以下每个场景的“检查点”都写入结果的 `checkpoints`（`step`、`passed`、`observation`）；任一检查点不通过即该场景不通过。所有浏览器场景共有的检查点：

- **G-1 页面可用**：页面加载成功，关闭首次进入时自动弹出的“使用引导”对话框（没有弹出时直接继续；依赖假设 A-2），能选择指定输入并点击“开始”，状态出现“正在听”。不满足时：页面不可达或 DNS/TLS 失败记为环境问题；页面可达但无法关闭模态对话框或找不到控件记为测试缺口（`testGaps`），并附页面截图与可见文字。
- **G-2 识别原文与非中文从不出现**：运行全程主页面字幕区与小窗（打开时）的每一次变化中，没有任何条目含谚文或日文假名，也没有任何条目与素材某句原文相同。
- **G-3 无 error/fatal 日志**（参考检查，计入 IQA-309 的“真实浏览器中止”检查点）：浏览器运行期间服务端 error/fatal 级日志条数记录到证据。

### IQA-301 韩语素材：定稿字幕全部为中文（AC-1、AC-3）

- 前置条件：新打开页面（干净浏览器上下文），选择“系统声音”；第 1 次运行同时打开小窗（供 IQA-307 使用）。
- 操作：点击“开始”，播放 KO-5 全部 5 句，等待定稿后点击“停止”；同一素材连续运行 3 次（每次新上下文）。
- 检查点（每次运行）：
  1. G-1、G-2。
  2. 定稿条目数等于 5（每句恰好一条，FR-310）。
  3. 每条定稿字幕按 FR-301 判为中文，不含谚文。
  4. 中文提示条数为 0（PQ-301：出现即该次运行失败）。
- 通过判定：3 次运行全部满足；结果记录每次运行的定稿条数、提示条数、逐条判定。
- 证据：每次运行的字幕变化记录（JSON）、请求记录、结束时截图。

### IQA-302 日语素材：定稿字幕全部为中文（AC-2、AC-3）

- 前置条件、操作：同 IQA-301（不打开小窗），素材换为 JA-5。
- 检查点：同 IQA-301，“不含谚文”换为“不含日文假名”；全汉字条目按 FR-302 判为中文。
- 通过判定：3 次运行全部满足。

### IQA-303 定稿非中文 → 重新翻译得到中文（系统声音）（AC-4）

- 前置条件：选择“系统声音”，打开小窗（供 IQA-307）；受控：KO-5 第 3 句的定稿阶段响应全部改写为非中文，重新翻译请求原样走真实服务。
- 操作：点击“开始”，播放 KO-5（第 3 句之后还有 2 句），定稿后停止。
- 检查点：
  1. G-1、G-2（含：注入的“한”从未出现在主页面或小窗）。
  2. 注入有效：至少一个被改写的响应被页面完整读取（依赖假设 A-9）。
  3. 第 3 句恰好发生 1 次重新翻译请求。
  4. 不留空白、不缩短：第 3 句条目第一次出现中文临时译文后，直到显示定稿译文之前的每一次变化中都不为空；音频结束后到定稿前文字长度不减少（文字被替换为更长的中文临时译文允许）。
  5. 第 3 句最终显示中文定稿译文；定稿条目数等于 5，其余各句均为中文；提示条数为 0。
- 证据：字幕变化记录、请求记录（含改写标记）、截图。

### IQA-304 定稿非中文 → 重新翻译得到中文（麦克风）（AC-4）

- 前置条件：选择“麦克风”；受控条件同 IQA-303。不打开小窗。
- 操作、检查点：同 IQA-303 的 1～5。

### IQA-305 重新翻译仍非中文 → 中文提示，翻译继续（AC-5、AC-6）

- 前置条件：选择“系统声音”，打开小窗；受控：KO-5 第 1、2、3 句的定稿阶段响应与重新翻译响应全部改写为非中文，第 4、5 句正常。
- 操作：播放 KO-5，定稿后在点击“停止”前截取主页面与小窗。
- 检查点：
  1. G-1、G-2（主页面与小窗）。
  2. 第 1～3 句每句都发生 1 次重新翻译，且定稿显示“（此句未能翻译成中文）”。
  3. 第 4、5 句显示中文定稿译文；定稿条目数等于 5，顺序一致（FR-310）。
  4. 全程未出现“翻译已中断”，播放结束时状态仍为“正在听”（FR-309）。
  5. 样式区分：提示条目与正常定稿条目至少一项可见样式不同（颜色、字形、字重、装饰、透明度、背景、边框或伪元素内容）。
  6. 不刺眼：提示颜色不是警示红色；无动画、无闪烁；字号不大于正常定稿字幕；与背景对比度 ≥ 4.5:1（依赖假设 A-5）。
  7. 主页面与小窗一致：条目文字与提示/正常分类逐条相同，小窗中提示样式同样与正常条目不同（依赖假设 A-6）。
- 证据：主页面与小窗同一时刻截图、样式测量、字幕变化记录、状态记录。

### IQA-306 临时译文非中文 → 不显示、不重译、不提示（AC-12）

- 前置条件：两种输入各执行一次（系统声音、麦克风）；受控：KO-LONG 第 2 句（长句）在已有一次临时译文成功返回、且距句末仍大于 0.8 秒时，改写其后一个临时请求的响应为非中文；定稿正常。
- 操作：播放 KO-LONG，定稿后停止。
- 检查点：
  1. G-1、G-2（改写的“한”从未出现）。
  2. 注入有效：恰有 1 个临时请求被改写且被页面读取。
  3. 改写响应结束后，第 2 句条目继续显示此前的中文临时译文（不为空），直到下一次中文更新。
  4. 第 2 句没有重新翻译请求；全程无中文提示。
  5. 第 2 句最终定稿为中文；定稿条目数等于 3。
- 证据：字幕变化记录、请求记录。

### IQA-307 小窗与主页面逐条一致（AC-6）

### IQA-308 首个片段写出前中止（AC-7、AC-10）

- 前置条件：服务日志可读（`QA_SERVICE_LOGS_DIR`）；请求体模板已从浏览器捕获（依赖假设 A-1）；期间无其它测试流量。
- 操作：两种方式各一次，每次在独立时间窗内：
  - 主动取消：用 `fetch` + `AbortController` 发送 ABORT-TEXT 的翻译请求，发送后 150 毫秒（尚未收到任何响应正文字节）调用 `abort()`；
  - 断开连接：用底层 HTTPS 请求发送同样的请求，150 毫秒后销毁套接字；
  - 随后发起一次完整的正常翻译请求（短韩语句）。
- 检查点（每种方式）：
  1. 中止时刻确未收到任何响应正文片段。
  2. 时间窗内 error/fatal 级日志 0 条。
  3. 时间窗内 `client_aborted` 信息级记录恰 1 条，字段集符合依赖假设 A-7。
  4. 时间窗内日志检索 ABORT-TEXT 与正常请求的原文片段、收到的译文片段命中 0 次；脱敏标记 `***` 与任何凭据值命中 0 次（AC-10）。
  5. 服务未退出：随后的正常请求返回 200，响应含汉字、不含谚文。
- 日志不可读或时间窗未读到时：检查点 2～4 记为环境或平台问题。

### IQA-309 首个片段写出后中止（AC-8、AC-10）

- 操作：同 IQA-308，但在收到第一个含汉字的响应片段之后、响应结束之前中止（主动取消与断开连接各一次）；随后发起正常请求。
- 检查点：
  1. 中止时刻已收到含汉字的片段且响应尚未结束。
  2～5. 同 IQA-308 的 2～5。
  6. 真实浏览器中止（参考 G-3）：全部浏览器运行期间（客户端会按设计中止被取代的请求）error/fatal 级日志 0 条。

## 7. 结果归类

- **产品缺陷（`defects`）**：场景未达到上述检查点要求的已批准行为，例如字幕或小窗出现谚文/假名/注入内容、定稿条数不对、清晰素材出现提示、未重新翻译或多次重新翻译、提示样式不符、出现“翻译已中断”、中止期间出现 error/fatal 日志、`client_aborted` 条数不为 1、日志含内容或凭据、服务在中止后不可用。
- **测试计划问题 / 脚本未能完成验证（`testGaps`）**：找不到页面控件或字幕条目、无法捕获请求体模板导致直接请求被拒（4xx）、注入未生效（无匹配请求）、截止时间内未执行的场景。
- **环境或平台问题**：候选或依赖不可达、DNS/TLS 失败、语音合成不可用、浏览器无法启动、服务日志 `status` 非 `ok` 或时间窗未读到。`passed` 为 false，相应检查点注明原因，不计入产品缺陷。
- **测试缺口（`test-gap`）**：AC-9（G2 决定）；AC-13 按 G3 修订说明由技术负责人在 G3 按测试缺口确认（独立测试无法判定，结果写 `unverifiable` 并在 `note` 中写明人的决定）。

## 8. 证据与隐私

- 证据写入 `QA_EVIDENCE_DIR`：每次浏览器运行的字幕变化记录与请求记录（`run-*.json`，内容只有合成素材及其译文）、截图（`*.png`）、浏览器控制台日志、直接请求的过程记录（`abort-*.json`）、日志统计（`logs-summary.json`，只含条数、级别、字段名与命中数，不含日志正文）。
- 证据与输出中从不写入任何凭据值；服务日志正文不复制到证据中。
