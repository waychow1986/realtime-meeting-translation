# 企业实时翻译 · 系统声音实时翻译 产品规格

> 依据：已确认的意图第 2 版（交付输入，含 Q-01、Q-02 的人工答案）与需求原文 `request.json`；麦克风模式的既有行为以第 1 版规格 `.ai-delivery/features/001-v1/spec.md`（下称“第 1 版规格”）为基线。
> 本规格只描述“做成什么样”，不做技术选择。客户在需求原文中指定的服务约束（沿用现有 Azure Foundry 语音转文本与大模型翻译、沿用现有依赖实例）按原样作为约束引用。
> 标注“待 PQ-00x”的条目依赖“开放产品问题”中尚未由人决定的事项；在得到人工答案前，其中给出的取值只是推荐值，不是已决定的要求。

## 产品目标与边界

| 意图范围 | 产品行为边界 |
| --- | --- |
| INT-101 输入选择 | 开始前在“麦克风”和“系统声音”之间二选一，默认“麦克风”；一次使用只采集所选的一种音源（AC-01；不做的事“不混合两路输入”；A-04）。 |
| INT-102 系统声音实时翻译 | 选择“系统声音”后，借助浏览器自带的共享能力（共享标签页、窗口或整个屏幕并带上声音）取得电脑正在播放的声音，流式、自动识别语言、实时显示中文字幕，体验与麦克风模式一致（AC-02～AC-05）。 |
| INT-103 浏览器限制的中文说明 | 页面用中文说明系统声音模式的操作步骤、各浏览器/系统的支持情况与能采集到的声音范围；不支持或操作失败时给出中文原因与重新操作方法（AC-06、AC-07；Q-01 答案）。 |
| INT-104 仍为 Web App | 在浏览器中打开应用地址即可使用，不安装桌面应用、浏览器插件或驱动（AC-08）。 |
| INT-105 麦克风模式不退化 | 第 1 版已确认的 AC-01～AC-09 对麦克风模式仍全部通过（AC-09）。 |
| INT-106 服务与安全约束 | 沿用现有 Azure Foundry 语音服务（实时、语言自动识别）与大模型（关闭 reasoning）的现有依赖实例；浏览器无长期凭据；服务端日志无客户内容与画面内容（AC-10）。 |
| INT-107 正式产品界面 | 统一视觉设计：输入选择、开始/停止、四种状态一眼可辨；字幕区为主，可调字号；首次进入有中文引导；常见桌面分辨率与约 480 像素窄窗口下可用（AC-11）。 |
| INT-108 悬浮字幕小窗 | 在支持的浏览器中把字幕弹出为悬浮在其它窗口之上的独立小窗，与主页面显示同一份字幕；不支持时按钮不可用并以中文说明原因（AC-12；Q-02 答案）。 |

范围外（意图“不做的事”与假设）：桌面应用；要求安装插件或驱动（含虚拟声卡等回环驱动）；麦克风与系统声音混合输入；与 Teams 等会议软件或视频网站做插件或集成；中文以外的目标语言；保存或导出字幕、音频或共享画面；语音合成；新建语音或大模型依赖实例；移动端浏览器（A-01）；一次使用中途在两种输入之间热切换（A-04）；同一次使用中途切换发言语言（A-05）；登录（A-06）。

## 参与者与权限

| 参与者 | 说明 | 权限 |
| --- | --- | --- |
| 字幕使用者 | 在电脑上看外语视频、电影或参加线上会议，打开本应用查看中文字幕的人。 | 凭访问地址即可使用全部功能，不需要登录（A-06）。决定使用哪种输入；在系统声音模式下由本人在浏览器弹窗中决定共享哪个标签页、窗口或整个屏幕，以及是否共享音频。只能看到本页面采集的声音所产生的字幕。 |
| 被翻译的发言者 | 视频中的说话人或线上会议中的对方。 | 不操作应用；其声音经使用者电脑播放后被采集。 |
| 测试环境运维者 | 部署与配置测试环境的人员。 | 唯一可接触服务凭据的角色；凭据不向使用者浏览器暴露（AC-10）。 |

数据访问要求：

- 应用只在使用者通过浏览器弹窗明确授权后，才取得所选标签页、窗口或屏幕的声音；不在未授权时采集任何系统声音（AC-02、AC-07）。
- 浏览器为共享声音附带交出的画面不显示、不上传、不保存（A-02）；只有声音被用于识别。
- 系统声音模式下不使用麦克风；麦克风模式下不请求共享（AC-01）。
- 声音、识别文本、中文译文与共享画面不被保存，不写入服务端日志（AC-10；A-06；宪章“安全与隐私”）。
- 使用者浏览器在任何时候都不获得服务密钥或其它长期凭据（AC-10）。

## 用户故事

### US-101 选择输入方式（P1）
作为字幕使用者，我希望开始前能在“麦克风”和“系统声音”之间选择，且选了哪种就只采集哪种，以便按场景决定翻译谁的声音。引用 INT-101；覆盖 AC-01。

### US-102 把电脑播放的外语声音实时翻译成中文字幕（P1）
作为看英文视频或参加线上会议的使用者，我希望电脑正在播放的外语声音被流式翻译成中文字幕，且我自己对着麦克风说的话不会混进字幕，以便及时理解视频或会议对方的发言。引用 INT-102；覆盖 AC-02、AC-03、AC-04。

### US-103 结束系统声音翻译（P1）
作为使用者，我希望点击“停止”或在浏览器里“停止共享”后，应用不再采集声音、不再出字幕，并能重新开始。引用 INT-102；覆盖 AC-05。

### US-104 知道怎么操作、哪些浏览器能用（P1）
作为使用者，我希望页面用中文告诉我如何共享声音、哪些浏览器/系统支持、各自能采到哪些声音；操作失败或浏览器不支持时告诉我原因和怎么办。引用 INT-103；覆盖 AC-06、AC-07。

### US-105 打开即用（P1）
作为使用者，我希望不安装任何软件、插件或驱动就能使用系统声音模式。引用 INT-104；覆盖 AC-08。

### US-106 麦克风模式不变差（P1）
作为第 1 版的使用者，我希望麦克风模式原有的能力全部保持。引用 INT-105；覆盖 AC-09。

### US-107 服务约束与内容保护（P1）
作为企业与客户，我希望系统声音模式同样使用现有的 Azure Foundry 服务实例，浏览器中没有长期凭据，服务端日志里没有识别文本、译文或共享画面。引用 INT-106；覆盖 AC-10。

### US-108 正式产品体验（P1）
作为使用者，我希望界面清晰：一眼看出当前用的输入、能否开始/停止和当前状态；字幕大而清楚、可调字号；第一次使用有引导；窗口缩窄到与视频并排时仍能读字幕。引用 INT-107；覆盖 AC-11。

### US-109 全屏看片或开会时也能看字幕（P1）
作为使用者，我希望把字幕弹出成一个悬浮在其它窗口之上的小窗，以便全屏看视频或在会议软件里时仍能看到实时中文字幕。引用 INT-108；覆盖 AC-12。

## 功能需求

### 输入方式选择

- **FR-101**：页面在字幕区之外的控制区显示“输入方式”选择，恰好包含两个选项，名称分别为“麦克风”和“系统声音”，同一时刻只能选中一个。（AC-01；A-08）
- **FR-102**：每次打开或刷新页面时，输入方式为“麦克风”；使用者未做选择即点击“开始”时按麦克风模式工作。（AC-01）
- **FR-103**：只有在“未开始”“已停止”“出错”状态下可以改变输入方式；处于“正在听”（及开始过程中）时输入方式选择不可操作，要换输入必须先停止再重新开始。（A-04）
- **FR-104**：麦克风模式下开始后，应用只使用麦克风，不弹出任何共享标签页/窗口/屏幕的浏览器弹窗；系统声音模式下开始后，应用只使用浏览器共享得到的声音，不请求、不使用麦克风（浏览器不显示本页面正在使用麦克风）。（AC-01、AC-02；不做的事“不混合两路输入”）

### 系统声音模式：开始与采集

- **FR-105**：系统声音模式下点击“开始”后，浏览器弹出其自带的共享选择窗口，使用者可在其中选择标签页、窗口或整个屏幕（以浏览器实际提供的选项为准），并勾选共享音频。（AC-02、AC-06；Q-01）
- **FR-106**：使用者完成共享且共享内容包含声音后，状态变为“正在听”，电脑正在播放、且在所共享范围内的外语声音被识别并翻译成中文字幕显示在页面上。（AC-02）
- **FR-107**：系统声音模式下，使用者对着麦克风说的话不出现在字幕中（无论是否同时有共享声音在播放）。（AC-02）
- **FR-108**：浏览器为共享声音而附带交出的标签页/窗口/屏幕画面：不在页面（含悬浮字幕小窗）上显示任何预览，不通过网络发送到任何地方，不被保存。（A-02；AC-10）
- **FR-109**：共享期间，使用者自己仍能照常听到被共享内容的原声，应用不将其静音或降低音量。（A-03）
- **FR-110**：按 Q-01 人工答案，承诺的采集范围为：
  - Windows 上最新版 Chrome、Edge：共享“整个屏幕”时可采集电脑正在播放的全部声音（包括桌面会议软件、本地播放器播放的声音）；共享单个“标签页”时可采集该标签页的声音。两种方式都必须可用。
  - macOS 上最新版 Chrome、Edge：共享单个“标签页”时可采集该标签页的声音（在线视频、网页版会议），必须可用；共享整个屏幕时的整机声音在浏览器支持时可用，不支持时由页面用中文说明（FR-118）。
  - 其它浏览器/系统：不作采集承诺，只在页面说明是否支持（FR-118、FR-119）。

### 系统声音模式：字幕行为（与麦克风模式一致）

- **FR-111**：一句较长的外语语音播放过程中，该句的中文临时字幕在这句话播放完之前出现，并随语音持续更新；这句话结束后被替换为该句的中文定稿字幕，定稿后不再改变。（AC-03）
- **FR-112**：页面上任何时候都不存在选择发言语言的控件；发言语言由语音服务自动识别；对英语语音输出对应的中文翻译。（AC-04；A-05）
- **FR-113**：字幕只显示中文译文，不显示原文；每句定稿字幕表达的意思与该句语音含义一致。（AC-04）
- **FR-114**：连续多句时，定稿字幕按播放先后顺序排列，每句语音恰好对应一条定稿字幕，不重复、不遗漏；所共享的声音静音期间不产生新字幕。（AC-04）
- **FR-115**：任一时刻最多一条临时字幕，位于所有定稿字幕之后；临时字幕与定稿字幕在样式上可区分（FR-131）。（AC-03、AC-11）

### 系统声音模式：结束

- **FR-116**：以下任一情况发生后，应用不再采集声音（浏览器的共享指示随之消失），字幕区不再出现新增或修改（包括结束时尚未定稿、仍在处理中的内容），状态变为“已停止”，输入方式选择和“开始”重新可用，已显示的字幕保留在页面上：
  1. 使用者点击页面上的“停止”；
  2. 使用者通过浏览器自身的“停止共享”结束共享；
  3. 被共享的标签页或窗口被关闭，导致共享结束。
  
  第 2、3 种情况下，页面另以中文提示“共享已结束”及重新开始的方法。（AC-05）
- **FR-117**：结束后再次点击“开始”（可先改选输入方式），新字幕接在已有字幕之后出现；系统声音模式每次开始都重新经过浏览器共享弹窗。（AC-05）

### 中文操作说明与支持情况

- **FR-118**：当输入方式为“系统声音”时（无需点击开始），页面以中文显示：
  1. 操作步骤：点击“开始” → 在浏览器弹窗中选择要共享的“标签页”“窗口”或“整个屏幕” → 勾选共享音频的选项（使用弹窗中实际出现的选项名称说明，如“同时共享标签页音频”“共享系统音频”） → 点击“共享”；以及如何结束（页面“停止”或浏览器“停止共享”）；
  2. 支持情况列表：逐项列出浏览器与操作系统的组合，每项写明“支持/部分支持/不支持”，以及选择标签页、窗口、整个屏幕时分别能采集到哪些声音（例如“只有该标签页的声音”“电脑播放的全部声音，包括会议软件和本地播放器”“采集不到声音”）；至少覆盖 Windows 与 macOS 上的 Chrome、Edge，以及 Firefox、Safari；
  3. 说明共享时附带的画面不会被显示、上传或保存，且使用者仍能听到原声。
  
  列表内容与交付时在测试环境实际验证的结果一致，至少包含 FR-110 中承诺的组合（A-07）。（AC-06）
- **FR-119**：在不支持系统声音采集的浏览器中选择“系统声音”时，页面立即以中文说明“当前浏览器不支持采集系统声音”，并列出可用的浏览器（Windows / macOS 上最新版 Chrome 或 Edge）；该模式下“开始”不可操作，不能进入“正在听”；改选“麦克风”后可正常使用。（AC-06）
- **FR-120**：在 FR-118 的列表标为“部分支持”的组合上，若使用者选择了该组合无法带声音的共享方式，按 FR-122 处理。（AC-06、AC-07）

### 系统声音模式：错误与提示

- **FR-121**：使用者在浏览器共享弹窗中点击“取消”或拒绝授权时，页面状态为“出错”，以中文提示原因（“未选择共享内容/共享授权被拒绝”）和重新操作方法（再次点击“开始”，在弹窗中选择内容并点击“共享”）；不进入“正在听”，不出现字幕。若浏览器已记住对本站点的拒绝，提示还说明如何在浏览器设置中恢复。（AC-07）
- **FR-122**：使用者完成共享但共享内容不包含声音（未勾选共享音频，或所选窗口/屏幕在该浏览器上无法带声音）时，页面状态为“出错”，以中文提示“所选共享内容没有包含声音”，并说明如何重新操作（再次点击“开始”，选择标签页或整个屏幕并勾选共享音频，并按 FR-118 指出该浏览器/系统上能带声音的方式）；此时应用立即结束该次共享（浏览器共享指示消失），不进入“正在听”。（AC-07）
- **FR-123**：任何不能产生字幕的错误（含语音识别或翻译服务不可用、连接中断）都不会让页面停在“正在听”而无提示：页面状态变为“出错”，以中文提示原因类别与恢复方法，采集停止，已显示的定稿字幕保留。错误提示中不含凭据、服务内部地址或客户内容。（AC-07、AC-10、AC-11）

### 无需安装

- **FR-124**：在 FR-110 承诺的浏览器/系统组合中，打开应用地址即可使用系统声音模式全部功能，过程中不出现、也不要求安装桌面应用、浏览器插件或驱动（含虚拟声卡）。（AC-08）

### 麦克风模式不退化

- **FR-125**：输入方式为“麦克风”时，第 1 版规格 FR-001～FR-022 规定的行为全部保持（打开即用、流式字幕、自动识别语言、只显示中文且含义一致、顺序不重不漏、开始/停止、真实服务约束、无长期凭据、日志无客户内容、刷新不保留、各页面互不显示字幕）；第 1 版 AC-01～AC-09 对麦克风模式全部通过。（AC-09）
- **FR-126**：麦克风模式相对第 1 版的允许变化仅限于本规格为整个页面统一规定的界面呈现：状态名称与“出错”状态（FR-128）、视觉样式、字号调整、首次引导、输入方式选择和悬浮字幕小窗入口（适用范围待 PQ-004）。这些变化不得使第 1 版任何验收标准失败。（AC-09、AC-11）

### 界面与视觉（适用于整个页面）

- **FR-127**：控制区同时显示输入方式选择、“开始”“停止”和当前状态；在 FR-135 规定的所有窗口尺寸下，打开页面不滚动即可看到这四者。“开始”只在可开始时可操作，“停止”只在“正在听”（及开始过程中）可操作，不可操作的按钮在外观上明显呈不可用。（AC-11）
- **FR-128**：当前状态只取以下四种之一，并以中文文字显示：“未开始”“正在听”“已停止”“出错”（开始过程中可显示一个过渡提示，如“正在启动…”，但不得长期停留）。每种状态除文字外还有区别于其它三种状态的颜色或图标；状态与实际是否在采集声音一致：只有“正在听”时在采集。（AC-11）
- **FR-129**：字幕区是页面上面积最大的区域；字幕文字是页面上字号最大的文字（含标题）。字幕默认字号、文字与背景对比度、行距的可判定取值待 PQ-003（推荐：默认字号不小于 28 像素，对比度不低于 7:1，行距不小于字号的 1.4 倍）。（AC-11）
- **FR-130**：字幕区自动保持最新字幕可见：有新字幕或临时字幕更新时，最新内容出现在字幕区可视范围内，无需使用者手动滚动；使用者可向上滚动查看本次已显示的较早字幕。（AC-11“字幕区为主要区域”的最小默认）
- **FR-131**：临时字幕与定稿字幕在样式上可区分：两者至少有一项可见样式不同（如颜色深浅、字形或标记），且不依赖仅在悬停时出现的信息；对比度要求同时适用于两者。（AC-11）
- **FR-132**：页面提供字号调整控件，提供至少 3 档字号（档位数待 PQ-003，推荐“小/中/大/特大”4 档，默认“中”）；调整后主页面与悬浮字幕小窗中的全部字幕（含临时字幕）立即按新字号显示，不中断正在进行的采集与翻译。字号设置是否跨刷新保留不作要求。（AC-11）
- **FR-133**：在某个浏览器中首次打开应用时，自动显示简短的中文使用引导，至少说明：选择输入方式、点击开始、系统声音模式需要在浏览器弹窗中选择共享内容并勾选共享音频、可调字号、可弹出字幕小窗（不支持时说明）。引导可一步关闭；关闭后在同一浏览器中再次打开应用时不再自动显示，但页面上有可随时重新打开引导的入口。关闭引导后即可直接操作“开始”。（AC-11）
- **FR-134**：界面文字（按钮、状态、说明、提示、错误信息、引导、支持列表）全部为中文；浏览器自身弹窗的文字不在此限。（A-08）
- **FR-135**：在桌面浏览器窗口内容区宽 1366～1920 像素、高 768～1080 像素的任意尺寸，以及宽约 480 像素（高 768 像素以上）的窄窗口中：页面不出现横向滚动条；控件与文字不相互重叠、不被截断；字幕每行完整显示（超长内容自动换行，不出现被截断或需横向滚动才能看到的字幕文字）。窄窗口下控制区可以换行或收拢，但 FR-127 的四项仍可见可用。（AC-11）

### 悬浮字幕小窗

- **FR-136**：控制区提供“弹出字幕小窗”按钮。在支持的浏览器（至少 Windows 与 macOS 上最新版 Chrome、Edge）中点击后，打开一个独立的字幕小窗，该小窗悬浮在其它窗口（包括其它浏览器窗口、桌面会议软件窗口、全屏播放的视频）之上，使用者切换到其它应用或全屏看视频时仍可见。（AC-12；Q-02）
- **FR-137**：字幕小窗与主页面显示同一份字幕：同一时刻两者的定稿字幕内容与顺序一致、临时字幕内容一致，更新同时发生；小窗内临时/定稿字幕的样式区分与字号设置与主页面一致；小窗始终让最新字幕可见。小窗内同时显示当前状态文字。小窗不显示共享画面（FR-108）。（AC-12）
- **FR-138**：使用者关闭字幕小窗后，主页面继续显示字幕并继续更新，采集与翻译不受影响；之后可再次弹出小窗，小窗显示当前的同一份字幕。主页面刷新或关闭时，小窗随之关闭。（AC-12）
- **FR-139**：在不支持字幕小窗的浏览器中，“弹出字幕小窗”按钮呈不可用状态，按钮旁以可见的中文文字（不依赖悬停）说明原因（“当前浏览器不支持悬浮字幕小窗”）并给出支持的浏览器；其余功能不受影响。（AC-12）
- **FR-140**：字幕小窗在麦克风模式与系统声音模式下的可用性待 PQ-004（推荐：两种模式都可用）。（AC-12）

### 服务约束（客户指定）

- **FR-141**：系统声音模式的语音转文字由现有 Azure Foundry 语音服务完成，使用其实时（流式）识别并开启语言自动识别；翻译由现有 Azure Foundry 大模型完成且关闭 reasoning；两者均为第 1 版已在用的同一依赖实例，不新建语音或大模型实例；在真实测试环境上验证。（AC-10；不做的事“不新建依赖实例”）

### 安全与隐私

- **FR-142**：在两种模式下，浏览器可见的页面源码、脚本，以及页面（含字幕小窗）发出和接收的全部网络请求与实时连接消息中，不出现服务密钥、连接字符串或其它长期凭据。（AC-10；宪章“安全与隐私”）
- **FR-143**：应用的服务端日志中不出现识别文本、中文译文、声音内容或共享画面内容，也不出现任何 secret。（AC-10；宪章“安全与隐私”）

### 数据与会话

- **FR-144**：字幕、声音和共享画面只在当前页面使用期间存在：刷新或关闭页面后字幕不保留，共享与采集随之结束；应用不提供保存或导出字幕、音频、画面的入口。仅界面偏好（是否已看过引导，可选的字号设置）可保留在使用者的浏览器中，其中不含客户内容。（A-06；不做的事）
- **FR-145**：每个浏览器页面只显示本页面采集的声音所产生的字幕；同时打开的其它页面互不显示对方的字幕。（第 1 版规格 FR-017 延续）

## 产品质量要求

- 由 AC-11 授权的界面质量要求见 FR-127～FR-135；其中“大字号、高对比、行距舒适、可调字号档位”的可判定取值待 PQ-003 决定。
- 对带背景音乐、音效或多人同时说话的声音，翻译质量的验收口径待 PQ-002 决定；在决定前，AC-04 的含义一致性只按清晰的外语测试语音判定。

## 行为模型

### US-101 选择输入方式
- 正常：打开页面 → 输入方式为“麦克风”→ 直接开始 → 浏览器只请求麦克风，不出现共享弹窗。（FR-101、FR-102、FR-104）
- 替代：改选“系统声音”→ 显示操作步骤与支持情况 → 开始 → 出现共享弹窗，不请求麦克风。（FR-104、FR-105、FR-118）
- 边界：“正在听”时尝试改选输入方式 → 选择不可操作。（FR-103）
- 边界：刷新页面 → 输入方式回到“麦克风”。（FR-102）

### US-102 系统声音实时字幕
- 正常：开始 → 在弹窗中选择播放英文视频的标签页并勾选共享音频 → 状态“正在听”→ 视频中每句英语在播放过程中出现中文临时字幕并更新，句末替换为定稿字幕；使用者仍听到原声；页面不出现共享画面。（FR-106、FR-108、FR-109、FR-111）
- 替代（Windows Chrome/Edge）：选择“整个屏幕”并勾选共享系统音频 → 桌面会议软件或本地播放器播放的英语产生中文字幕。（FR-110）
- 连续多句：定稿字幕按播放顺序排列，不重不漏；静音段不产生字幕。（FR-114）
- 干扰：使用者同时对着麦克风说话 → 这些话不出现在字幕中。（FR-107）
- 语言：全程不选择语言。（FR-112）

### US-103 结束系统声音翻译
- 正常：点击“停止”→ 浏览器共享指示消失 → 状态“已停止”→ 此后字幕区不变。（FR-116）
- 替代：点击浏览器“停止共享”或关闭被共享的标签页 → 同上，并提示“共享已结束”。（FR-116）
- 边界：结束时恰有一句话在播放或翻译中 → 结束后不再出现该句的新增或修改。（FR-116）
- 恢复：再次开始（可改选输入方式）→ 新字幕接在已有字幕之后。（FR-117）

### US-104 中文说明与失败提示
- 正常：选择“系统声音”→ 页面显示操作步骤与支持列表。（FR-118）
- 不支持的浏览器：选择“系统声音”→ 显示不支持说明与可用浏览器，无法进入“正在听”。（FR-119）
- 取消/拒绝共享 → “出错”+ 中文原因与重新操作方法。（FR-121）
- 共享无声音 → “出错”+ 中文原因与重新操作方法，共享立即结束。（FR-122）

### US-105 打开即用
- 正常：干净的浏览器配置中打开地址即可完成系统声音模式全流程，无任何安装要求。（FR-124）

### US-106 麦克风模式不变差
- 正常：麦克风模式下逐条执行第 1 版验收场景，全部通过。（FR-125、FR-126）

### US-107 服务约束与内容保护
- 正常：系统声音模式产生的字幕来自现有 Azure Foundry 语音与大模型实例；浏览器无长期凭据；服务端日志无客户内容。（FR-141～FR-143）

### US-108 正式产品体验
- 首次打开 → 显示中文引导 → 关闭 → 再次打开不自动显示，可从入口重新打开。（FR-133）
- 任一状态下控制区四项可见、状态一眼可辨。（FR-127、FR-128）
- 调整字号 → 主页面与小窗字幕立即变化，采集不中断。（FR-132）
- 缩窄窗口到约 480 像素 → 无横向滚动条，字幕完整可读。（FR-135）

### US-109 悬浮字幕小窗
- 正常（支持的浏览器）：弹出小窗 → 切换到全屏视频或会议软件 → 小窗仍在最上层显示与主页面相同的实时字幕。（FR-136、FR-137）

## 业务状态、业务数据规则与不变量

状态：

```
未开始 ─开始(授权成功且有声音)→ 正在听
未开始/已停止/出错 ─开始失败(拒绝、取消、无声音、无麦克风)→ 出错
正在听 ─停止 / 浏览器停止共享 / 共享内容被关闭→ 已停止
正在听 ─服务中断等错误→ 出错
已停止/出错 ─开始→ 正在听 或 出错
任意状态 ─刷新/关闭页面→（页面重新进入）未开始
```

不变量：

1. 只有“正在听”时采集声音；其它状态下浏览器不显示本页面在使用麦克风或在共享。（FR-116、FR-122、FR-128）
2. 任一时刻只采集一种音源，且与开始时所选输入方式一致。（FR-104）
3. 不处于“正在听”时，字幕区不发生任何新增或修改。（FR-116）
4. 任一时刻最多一条临时字幕，位于所有定稿字幕之后；定稿字幕一经出现不再改变或移除（刷新/关闭页面除外），顺序与语音顺序一致，与句子一一对应。（FR-111、FR-114、FR-115）
5. 字幕区与字幕小窗只包含中文译文，二者内容一致。（FR-113、FR-137）
6. 共享画面从不显示、从不离开使用者的浏览器、从不被保存。（FR-108）
7. 客户内容不保存、不写服务端日志；浏览器不持有长期凭据。（FR-142～FR-144）

## 安全、隐私与可访问性行为

- 凭据：两种模式下浏览器可见内容（页面源码、脚本、字幕小窗、全部网络请求与实时连接消息）不含服务密钥、连接字符串或其它长期凭据。（FR-142；AC-10；宪章“凭据保留在服务端”）
- 客户内容：声音、识别文本、译文与共享画面不保存、不写入服务端日志。（FR-143、FR-144；AC-10；宪章“绝不记录 secret 或客户内容”）
- 共享画面：只为取得声音而存在，不显示、不上传、不保存。（FR-108；A-02）
- 授权与最小采集：只在使用者于浏览器弹窗中明确授权后采集；只采集所选的一种音源；结束后立即停止采集并结束共享。（FR-104、FR-116、FR-122；宪章“least privilege”）
- 访问控制：不做登录，凭访问地址使用。（A-06）
- 可访问性：当前没有获批准的可访问性等级要求；AC-11 的字号、对比度、行距取值见 PQ-003。

## 性能、可靠性与其他质量边界

当前没有获批准的额外要求（不设定时延数值、可用率、并发、连续使用时长上限）。流式时序只按 AC-03 的相对关系判定（IQA-103）。带背景音乐、音效或多人重叠说话时的识别与翻译质量口径待 PQ-002。

## 成功标准

- **SC-101**：输入方式默认“麦克风”；选哪种就只采集哪种，开始后浏览器请求的权限与所选一致。（AC-01）
- **SC-102**：系统声音模式下，共享标签页中播放的英语产生中文字幕；同时对麦克风说的话在字幕中出现 0 次。（AC-02）

## 测试策略

### 开发者验证

开发者提交前在真实测试环境的现有依赖实例上按 IQA-101～IQA-123 自测，并在麦克风模式下重跑第 1 版验收场景（IQA-113）；可另做不依赖外部服务的局部检查，但这些检查不能替代验收证据（宪章“测试与质量”）。

### Independent QA 验收

独立测试按“验收场景”逐条执行 IQA-101～IQA-126，全部针对真实测试环境与现有依赖实例；使用合成的英语测试语音及参考译文；证据中不得包含凭据；IQA-115、IQA-116 只记录命中数量；IQA-124～IQA-126 的执行方式按 PQ-001 的人工答案确定。

### 总体通过与失败标准

- 通过：IQA-101～IQA-126 全部通过（其中依赖 PQ 的判定按人工答案执行），AC-01～AC-12 均有对应证据。
- 失败：任一 IQA 失败；任一 AC 缺少来自真实测试服务的证据；证据来自 Mock；或第 1 版任一验收场景在麦克风模式下失败。
