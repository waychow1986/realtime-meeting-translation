选择输入方式后点击“开始”，发言内容会自动识别并以中文字幕显示在这里。

    使用引导

    1. 选择输入方式：“麦克风”识别您身边的发言；“系统声音”识别电脑正在播放的声音（如网页会议、在线视频）。
    2. 点击“开始”：麦克风模式需在浏览器提示时允许使用麦克风；随时点击“停止”结束。
    3. 系统声音：点击“开始”后，在浏览器弹出的共享窗口中选择要翻译的内容（如会议所在的标签页），并勾选共享音频（如“同时分享标签页中的音频”）后再点击“分享”。
    4. 调整字号：在“字号”中选择“小 / 中 / 大 / 特大”，字幕立即按新字号显示。
    5. 字幕小窗：可点击“弹出字幕小窗”让字幕悬浮在会议或视频窗口之上；浏览器不支持时该按钮不可用，并会显示原因。

    字幕只显示在当前页面，刷新或关闭页面后即清空。可随时点击右上角“使用引导”再次查看本说明。
