    系统声音：操作步骤与支持的浏览器
    1. 先在其它标签页或软件中准备好要翻译的视频或会议。
    2. 点击“开始”，浏览器会弹出共享选择窗口。
    3. 看网页视频或网页版会议：选择“标签页”，选中正在播放的标签页，并保持“同时分享标签页中的音频”处于打开状态。
    4. 看桌面会议软件或本地播放器（Windows）：选择“整个屏幕”，并打开“同时分享系统音频”。
    5. 点击“分享”，状态变为“正在听”后即开始出字幕。
    6. 结束：点击本页“停止”，或点击浏览器提示条上的“停止共享”。
    • 共享时浏览器附带的画面不会被显示、上传或保存，只使用声音。
    • 你仍能照常听到原声。
    • 背景音乐、音效或多人同时说话时，字幕可能不完整或不准确。
    • 全屏观看视频时，可点击“弹出字幕小窗”查看字幕（需浏览器支持）。

    使用引导

    1. 选择输入方式：“麦克风”识别您身边的发言；“系统声音”识别电脑正在播放的声音（如网页会议、在线视频）。
    2. 点击“开始”：麦克风模式需在浏览器提示时允许使用麦克风；随时点击“停止”结束。
    3. 系统声音：点击“开始”后，在浏览器弹出的共享窗口中选择要翻译的内容（如会议所在的标签页），并勾选共享音频（如“同时分享标签页中的音频”）后再点击“分享”。
    4. 调整字号：在“字号”中选择“小 / 中 / 大 / 特大”，字幕立即按新字号显示。
    5. 字幕小窗：可点击“弹出字幕小窗”让字幕悬浮在会议或视频窗口之上；浏览器不支持时该按钮不可用，并会显示原因。

    字幕只显示在当前页面，刷新或关闭页面后即清空。可随时点击右上角“使用引导”再次查看本说明。
